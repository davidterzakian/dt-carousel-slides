# dt-carousel-slides

Slide images for David Terzakian's Laval real estate carousels (Instagram + TikTok, scheduled through Metricool).

- `slides/<date>-<slug>/slide-NN.png`: each carousel, 1080x1350. Metricool pulls them from their raw.githubusercontent.com links.
- `_kit/`: the renderer (`render.py`), fonts, DT signature logo and headshot used to build every carousel.

Only carousel images belong here: this repository is public.
